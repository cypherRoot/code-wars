## Why it matters

Almost all data in a pipeline passes through these four shapes at some point. A JSON API response becomes a **list of dicts**. A database row comes back as a **tuple**. "Have I seen this ID before?" is a **set**. You'll use them all daily.

<JsBridge>

```js
const amounts = [114.49, 29.99];        // Array
const customer = { name: "Priya" };     // Object
const seen = new Set([101, 102]);       // Set
amounts.push(42.5);
customer.city ?? "unknown";
```

```python
amounts = [114.49, 29.99]               # list
customer = {"name": "Priya"}            # dict
seen = {101, 102}                       # set
amounts.append(42.5)
customer.get("city", "unknown")
```

<Breaks>
Dict keys need quotes (`{"name": ...}`), and you read them with `customer["name"]`, never `customer.name`. Reading a missing key with brackets **raises an error** instead of giving `undefined`. Also, `{}` is an empty **dict**. An empty set is `set()`.
</Breaks>

</JsBridge>

Slicing `xs[start:stop]` takes items from `start` up to, **but not including**, `stop`. Leave either side out to go to the edge: `xs[:3]` gives the first three, `xs[-2:]` the last two.

## Sets and tuples

<Worked id="sets-tuples" />

| Need | Use |
|---|---|
| An ordered sequence you'll add to | `list` |
| Look things up by a key | `dict` |
| A fixed record, like a row from a database | `tuple` |
| Uniqueness, or fast "have I seen it?" checks | `set` |
